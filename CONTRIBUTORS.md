# ArcadeDuck Contributors and Credits

ArcadeDuck is built on the final GPL-era DuckStation codebase. This file preserves the upstream DuckStation credits while also documenting contributions and acknowledgements specific to ArcadeDuck.

## ArcadeDuck

### Project Development

- [@StillJC](https://github.com/StillJC) - ArcadeDuck development and maintenance

### Project Foundations and Research

- The DuckStation developers and contributors, whose GPL-era codebase provides the foundation for ArcadeDuck
- Arcade1Up contributors whose *The Simpsons Bowling* work helped kick off the project
- [@t-dollaz](https://github.com/t-dollaz) for the intermediate *The Simpsons Bowling* / Baby Phoenix work
- The MAME developers for hardware research, documentation, and device implementations used as essential reference material

### Testing and Hardware Research

- Everyone testing games, reporting bugs, researching arcade hardware, supplying technical information, and helping validate ArcadeDuck
